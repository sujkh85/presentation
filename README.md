# pwdff console E2E — 지금의 E2E, 그리고 AI-assisted E2E Testing

사내 발표용 인터랙티브 사이트입니다. 앞부분은 지금 돌고 있는 콘솔 E2E 테스트 현황, 뒷부분은 업무망에서 시작하려는 **AI-assisted E2E Testing**입니다. 반짝이는 은하 콘셉트이며, 회사 코드는 포함하지 않습니다.

## 실행

설치나 빌드 없이 Python 3와 브라우저만 있으면 됩니다.

```sh
npm start          # 또는
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:4173 에 접속합니다. ES 모듈을 쓰므로 `index.html`을 더블클릭하지 말고 로컬 서버로 여세요.

## 구성

여섯 장면입니다. 소개 → 검증 배경 → 현재 E2E → AI-assisted → 검증 범위 → 발표 자료.

**전반부 · 지금 돌고 있는 것** (NCP 독립망 · Playwright headless)

| 시나리오 | 내용 |
|---|---|
| 풀 테스트 | 매일 08:50, dev 콘솔 전체 시나리오 |
| 로그인 감시 | 1시간마다 로그인만. 실패할 때만 메일 |
| pub 수동 실행 | 로그인 자동화가 안 되어 사람이 로그인 후 실행 |

**후반부 · 앞으로 할 것** (업무망 · 도입 예정)

| 시나리오 | 내용 |
|---|---|
| 2차 인증 통과 | Gmail MCP로 인증 메일을 읽어 2FA를 넘김 |
| 다국어 레이아웃 | 영어 전환 시 깨지는 화면을 AI가 직접 봄 |
| 기획서 기반 QA | 기획서에서 확인 항목을 도출해 실행 |

전반부의 한계 세 가지가 후반부 세 가지와 1:1로 대응합니다. 자세한 대응은 `E2E_ANALYSIS.md`에 있습니다.

## 발표

- 오른쪽 '다음 단계'로 왼쪽 재현 화면을 진행합니다. 화면 속 버튼은 시연 그림이며 실제 테스트를 실행하지 않습니다.
- 발표 모드에서 ←/→는 시나리오 내부 단계 이동입니다. **현재 E2E와 AI-assisted 두 섹션 모두** 단계 이동이 동작하며, 나머지 섹션에서는 장면 이동입니다.
- PageUp/PageDown은 장면 이동, Home/End는 처음/마지막, Esc는 발표 모드 종료입니다.
- 상단 ▤ 또는 발표 자료에서 약 10분 대본을 봅니다. 앞 6분이 현황, 뒤 4분이 AI입니다.
- 상단 ⛶는 전체화면입니다. 별빛은 발표 모드에서도 계속 반짝이고, reduced-motion에서만 멈춥니다.
- 단계를 넘기면 재현 화면이 진행 방향으로 들어오고, 로그·체크리스트·인증 코드가 순서대로 나타납니다. 실행 중 표시(도는 아이콘, 흐르는 빛, 커서)는 장식이며 실제 실행 상태가 아닙니다.

## 회사 저장소에서 채우기

`E2E_PRESENTATION_ONESHOT.md`를 회사 저장소를 연 코딩 AI에게 그대로 전달합니다. 프롬프트 첫 부분에 이 프로젝트에서 이미 확정된 사실과, 저장소에서 찾아 채워야 할 항목이 정리돼 있습니다. 사이트에서도 다운로드됩니다.

`dist/scenarios.js`의 데이터와 `dist/app.js`의 `SCREENS`를 실제 흐름에 맞게 교체합니다. 데이터를 바꿀 때 시나리오 수 표시, 대본, 검증 범위 설명도 함께 갱신하세요. **원본 리포트와 연결하기 전에는 통과 수치나 성공 상태를 만들지 않습니다.**

## 구조와 검증

- `dist/index.html`: 여섯 발표 섹션
- `dist/styles.css`, `dist/galaxy.css`: 레이아웃과 은하 스타일, 콘솔 재현 화면 부품
- `dist/motion.css`: 등장·전환·재현 화면 안의 움직임. reduced-motion에서 전부 꺼집니다
- `dist/app.js`: 단계 플레이어 2개(`cur-` / `ai-`), 25개 재현 화면, 발표 모드, 모달, 스크롤 진입·진행 막대·시차 이동
- `dist/scenarios.js`: `scenarios`(현황) · `aiScenarios`(AI) · `contexts` · `notes`
- `tests/presentation.test.mjs`: 브라우저가 아닌 DOM 모형으로 상태 전환 검증

```sh
npm test    # node --test tests/presentation.test.mjs
```

이 검증은 발표 사이트의 상태 로직만 확인합니다. 콘솔 E2E의 실제 실행 결과가 아닙니다. 범위는 `VALIDATION.md`를 보세요.

## 주의

이 저장소는 공개 상태입니다. 실제 콘솔 URL, 계정, 내부 호스트명, 실제 발견 사항을 커밋하기 전에 공개 범위를 먼저 확인하세요. 현재 자료의 예시 값(예약 관리 기능, 인증 코드, 발견 2건)은 모두 설명용 가상입니다.
