# ORBIT — 별빛을 따라, 사용자 여정의 끝까지

반짝이는 은하 콘셉트의 한국어 E2E 발표 사이트입니다. 아스트라에 오라티오의 대형 비주얼, 중앙 강조 카드, 대각선 흑백 구성과 섹션 흐름을 바탕으로 제작했습니다. 회사 코드는 사용하지 않았습니다.

## 실행

설치나 빌드 없이 Python 3와 브라우저만 있으면 실행됩니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:4173 에 접속합니다. ES 모듈을 사용하므로 index.html을 더블클릭하지 말고 로컬 서버로 여세요. 이미지와 코드는 로컬에 있어 서버 실행 후 인터넷 연결 없이 핵심 발표가 가능합니다.

## 발표

- 소개 → 검증 배경 → 시나리오 → 검증 범위 → 발표 자료 순서입니다.
- 시나리오는 정상 예매 5단계, 좌석 충돌 4단계, 결제 실패 4단계입니다.
- 오른쪽 ‘다음 단계’로 왼쪽 설명용 서비스 화면을 진행합니다. 화면 속 예매·결제 버튼은 시연 그림이며 실제 주문을 만들지 않습니다.
- 발표 모드에서 ←/→는 시나리오 내부 단계 이동, 나머지 섹션에서는 장면 이동입니다.
- PageUp/PageDown은 장면 이동, Home/End는 처음/마지막, Esc는 발표 모드 종료입니다.
- 상단 ▤ 또는 발표 자료에서 약 7분의 대본을 확인합니다. 대본 시간은 시연을 포함한 권장 배분입니다.
- 상단 ⛶는 전체화면입니다. 지원하지 않는 환경에서는 일반 발표 모드를 사용합니다.
- 별빛 애니메이션은 발표 모드와 reduced-motion에서 멈춥니다.

## 회사 프로젝트에 적용

`E2E_PRESENTATION_ONESHOT.md`를 회사 저장소를 연 코딩 AI에게 전달합니다. 프롬프트에는 코드 근거 추적, 실제 실행 상태 구분, 발표 구현과 검증 요구가 있습니다. 원샷 프롬프트는 사이트에서도 다운로드할 수 있습니다.

`dist/scenarios.js`의 데이터와 `dist/app.js`의 재현 화면을 실제 사용자 흐름에 맞게 교체합니다. 데이터를 바꿀 때 시나리오 수 표시, 대본, 범위 설명도 함께 갱신하세요. 원본 보고서와 연결하기 전에는 통과 수치나 성공 상태를 만들지 않습니다.

## 구조와 검증

- `dist/index.html`: 다섯 발표 섹션
- `dist/styles.css`, `dist/galaxy.css`: 레퍼런스 구조와 은하 스타일
- `dist/app.js`: 단계 시연, 카드 선택, 발표 모드, 모달
- `dist/scenarios.js`: 예시 시나리오와 발표 대본
- `dist/assets/galaxy.png`: 프로젝트에 포함된 생성 은하 이미지
- `tests/presentation.test.mjs`: 브라우저가 아닌 가벼운 DOM 모형으로 상태 전환 검증

```sh
node --test tests/presentation.test.mjs
```

이 검증은 발표 사이트의 상태 로직을 확인합니다. 가상 예매 서비스의 실제 E2E 실행 결과가 아닙니다. 검증 범위는 `VALIDATION.md`를 확인하세요.
